# 새 메모

Finder의 폴더·바탕화면에서 우클릭으로 파일을 만들고 필요할 때 직접 열어 편집하는 macOS 앱입니다. Markdown(`.md`)·텍스트(`.txt`)를 기본 제공하며, 사용자 지정 확장자와 시작 템플릿을 지원합니다. 인터넷 연결이나 계정 없이 실행합니다.

현재 공개 버전은 **1.4.3**입니다. macOS 13 이상을 대상으로 하며 Apple Silicon·macOS 27.0.1에서 검증했습니다. Developer ID 서명·공증은 아직 적용하지 않았습니다. 빌드 방법은 아래 **빌드·설치**를 참고하세요.

## 사용 방법

1. `새 메모.app`을 실행합니다.
2. 처음 한 번 **Finder 확장 설정 열기…**를 눌러 **새 메모**를 켭니다. macOS 27에서는 시스템 설정 → 일반 → 로그인 항목 및 확장 프로그램 → 파일 제공자에 표시됩니다.
3. 폴더나 바탕화면의 빈 공간을 우클릭하고 **새 Markdown 파일** 또는 **새 텍스트 파일**을 선택합니다.
4. 빈 파일이 생성되고 Finder에서 선택됩니다. 더블 클릭하거나 `⌘↓`로 직접 열고, 편집 후 `⌘S`로 저장합니다.

일반 폴더 자체를 우클릭하면 해당 폴더 **안에** 생성합니다. 앱·문서 패키지(`.app`, `.rtfd`, `.key` 등)는 내부를 보호하기 위해 부모 폴더에 생성합니다. 파일을 우클릭하면 그 파일이 있는 폴더에 생성합니다. 여러 항목을 선택했을 때에는 생성 메뉴를 표시하지 않습니다. 같은 이름이 있으면 `새 메모 2.md`, `새 메모 3.md`처럼 번호를 붙이며 기존 파일을 덮어쓰지 않습니다.

앱의 시작 화면에서도 저장할 폴더를 선택해 새 파일을 만들거나 기존 메모를 열 수 있습니다. 앱을 종료해 두어도 Finder 메뉴에서 파일을 만들 수 있으며, 파일 생성 후 호스트는 종료됩니다.

## 새 폴더 만들기 (1.3)

Finder 우클릭 메뉴나 도구 막대의 **새 폴더 만들기**를 선택하면 해당 위치에 빈 `새 폴더`를 만들고 Finder에서 선택합니다. 기존 항목이 있으면 `새 폴더 2`, `새 폴더 3`처럼 번호를 붙입니다. 파일 형식을 모두 꺼 두어도 폴더 생성은 사용할 수 있습니다. 앱 시작 화면에서도 저장할 폴더를 선택한 뒤 **새 폴더 만들기**를 누를 수 있습니다. 편집기나 미리보기는 열지 않습니다.

## 파일 형식과 템플릿 (1.1)

앱에서 **⌘,** 또는 Finder 메뉴의 **파일 형식 및 템플릿…**을 선택하세요.

- 형식을 선택해 메뉴 표시명, 확장자, 기본 파일 이름, 시작 내용을 편집합니다. 템플릿을 비워 두면 빈 파일이 생성됩니다.
- JSON·YAML·HTML·CSV·Shell·`.env`·`.gitignore` 프리셋도 준비되어 있습니다. **Finder 메뉴에 표시**를 켜서 사용하세요.
- **추가**로 `.toml`, `.tsx` 등 원하는 텍스트 형식을 등록합니다. 확장자에는 앞의 점을 입력하지 않습니다. `.env` 같은 파일은 확장자를 비우고 기본 파일 이름에 `.env`를 입력합니다.
- **↑ / ↓**로 Finder 메뉴와 시작 화면의 표시 순서를 바꿉니다.
- **우클릭 메뉴를 ‘새 파일’ 하위 메뉴로 모으기**로 메뉴를 간결하게 만듭니다.
- **기본 파일 이름**은 형식별로, **기본 폴더 이름**은 공통으로 지정합니다. 새 항목은 이름 입력 없이 만들고 Finder에서 선택만 합니다. 파일을 열려면 더블 클릭하거나 `⌘↓`를 누르세요.
- **저장**해야 반영되며, **취소**나 창 닫기는 변경을 버립니다. 다음 Finder 메뉴를 열 때 최신 설정을 읽습니다.

Finder의 **보기 → 도구 막대 사용자화…**에서 **새 메모** 버튼을 추가하면 도구 막대에서도 같은 형식 목록을 사용할 수 있습니다. 최근 항목·검색 결과처럼 대상 폴더가 없는 위치에서는 파일 생성이 비활성화됩니다. iCloud 등 다른 파일 제공자가 관리하는 폴더에서는 macOS가 우클릭 확장을 제한할 수 있습니다.

최대 64개 형식, 템플릿당 UTF-8 256KB를 지원합니다. 경로 문자가 들어간 이름, 잘못된 확장자, 텍스트로 읽을 수 없는 제어문자는 저장하지 않습니다. 점 파일의 이름도 충돌하면 `.env 2`처럼 번호를 붙입니다. Shell 템플릿은 일반 파일로 만들며 실행하지 않습니다.

## 손상된 설정 보호 (1.4.3)

설정이 손상되면 설정 창에 기본값을 표시하는 이유를 안내합니다. 저장할 때 기존 원본 전체를 호스트 설정 도메인 `kr.techkwon.NewMemo`의 `filePresetSettings.v1.recovery`에 먼저 보존합니다. 이미 다른 원본의 백업이 있거나 백업을 저장하지 못하면 새 설정 저장을 중단합니다. 설정을 읽기만 할 때는 원본을 바꾸지 않습니다.

수동 복구 전 앱을 종료하고 `defaults export kr.techkwon.NewMemo`로 전체 도메인을 별도 파일에 보관하세요. 복구 키의 원본을 추출해 JSON 내용을 수리한 뒤 유효한 설정으로 복원해야 합니다. 손상된 백업을 그대로 본 설정에 복사하면 다시 손상 상태가 됩니다. 백업을 별도 파일로 보관하기 전에는 원본이나 복구 키를 삭제하지 마세요.

## 생성 방식 (1.4.1)

새 파일은 기본 이름으로 생성하고 Finder에서 선택합니다. 편집기를 자동으로 열지 않습니다. **이름 지정해서 만들기** 메뉴와 시작 화면의 **만들 때 이름 입력**은 제거했습니다. **파일 형식 및 템플릿…**에서 파일 이름과 공통 폴더 이름을 바꿀 수 있습니다. 같은 이름이 있으면 번호를 붙여 보존합니다.

복사한 폴더 경로로 이동하려면 Finder에서 **⇧⌘G → ⌘V → Return**을 누르세요. 전체 파일 경로를 복사했다면 마지막 파일 이름을 지우고 폴더 경로로 이동할 수 있습니다.

## Finder 작업 도구 (1.4)

- **전체 경로 복사**: 파일·폴더를 선택해 우클릭하면 메뉴에 바로 표시됩니다. 여러 항목은 줄바꿈으로 구분해 복사하며 최대 128개를 지원합니다.
- **현재 폴더 경로 복사**: 빈 공간 우클릭 또는 항목을 선택하지 않은 도구 막대 메뉴에서 현재 폴더의 경로를 복사합니다. 도구 막대에서 항목을 선택한 경우에는 **전체 경로 복사**로 표시됩니다.
- **파일 작업 → 파일 이름·목록 복사**: 선택한 항목의 이름만 줄바꿈으로 구분해 복사합니다.
- **클립보드를 파일로 저장 → 텍스트 / Markdown / 이미지…**: 현재 클립보드를 이름 지정 후 파일로 저장하고 Finder에서 선택합니다. Maccy에서 고른 내용을 사용할 수 있으며 기록을 따로 저장하거나 감시하지 않습니다.
- **파일 작업 → 폴더로 복사… / 폴더로 이동…**: 목적지를 고릅니다. 보내기 창의 **이 폴더를 즐겨찾기에 추가**를 켜면 다음 작업에서 선택할 수 있습니다(최근 등록 순 최대 8개). 같은 이름은 번호를 붙이고 기존 항목을 보존합니다. 자기 폴더 안으로 보내기·같은 위치로 이동은 거부합니다.
- **여기서 터미널 열기**: 해당 폴더를 macOS Terminal에서 엽니다. 셸 명령 문자열을 조립하거나 실행하지 않습니다.
- 문서 제목 표시줄의 **핀 버튼** 또는 **보기 → 메모 창 맨 위 고정**: 해당 메모 창만 다른 일반 창 위에 표시합니다. 다시 누르면 해제합니다.

클립보드 글은 UTF-8 256KiB, 이미지는 인코딩 데이터 16MiB·각 변 4096px·총 4,194,304화소 이하입니다. PNG는 재인코딩하지 않고, TIFF는 크기를 확인한 뒤 PNG로 변환합니다. 클립보드 제공 앱이 데이터를 전달하는 순간의 임시 메모리까지 제한할 수는 없습니다. 전송은 네이티브 파일 API로 처리하며 원문 전체를 앱 메모리에 읽지 않습니다. 파일 이동은 같은 볼륨에서 지원하고, 다른 볼륨에서는 원본을 보존한 채 복사 기능을 안내합니다.

Finder와 앱 사이의 작업 URL에는 사용자별 확인 토큰을 붙입니다. 외부에서 인증 없이 보낸 작업 URL은 실행하지 않습니다. 이 토큰은 같은 사용자 권한의 다른 로컬 앱을 격리하는 보안 경계가 아닙니다. 클립보드 저장 창에는 저장 폴더를, 전송 창에는 원본 항목 수와 위치를 표시합니다.

파일 생성·클립보드 저장·파일 작업·터미널 실행을 위해 추가 상주 프로세스나 주기적 감시를 만들지 않습니다. 연속 요청 전달을 위해 단발 작업 후 0.75초만 종료를 대기하고 새 요청이 오면 대기를 다시 잡습니다. 앱 종료 상태에서 단발 작업을 실행하면 작업이 끝난 뒤 호스트 앱이 종료됩니다. 열려 있는 메모나 시작 화면이 있으면 유지합니다. 고정한 메모 창을 열어 둔 동안은 편집기가 실행됩니다.

## 편집 단축키

| 기능 | 단축키 |
| --- | --- |
| 새 메모 시작 화면 | `⌘N` |
| 파일 형식 및 템플릿 | `⌘,` |
| Markdown 편집 / 미리보기 | `⇧⌘P` |
| 기존 파일 열기 | `⌘O` |
| 저장 | `⌘S` |
| 다른 이름으로 저장 | `⌥⇧⌘S` |
| 실행 취소 / 다시 실행 | `⌘Z` / `⇧⌘Z` |
| 찾기 / 다음 찾기 | `⌘F` / `⌘G` |

새 파일은 UTF-8이고, 기존 UTF-8·UTF-16 파일을 읽고 저장합니다. 읽을 수 없는 인코딩과 바이너리는 오류를 표시합니다. macOS 문서 자동 저장과 최근 50단계의 실행 취소를 지원하며, 기존 기본 편집기 설정은 변경하지 않습니다.

## Markdown 미리보기와 메모리 (1.2)

`.md`·`.markdown` 문서 오른쪽 위의 **편집 / 미리보기**를 누르거나 **⇧⌘P**를 누릅니다. 원문을 바꾸지 않고 제목, 굵게·기울임·취소선, 목록·체크박스, 인용, 코드, 링크와 간단한 표를 보여 줍니다. 편집으로 돌아와 수정하고 다시 미리보기를 열면 최신 내용이 반영됩니다. 미리보기에서도 저장할 때는 Markdown 원문을 저장합니다.

미리보기는 AppKit 텍스트 뷰로 구현했습니다. 웹 브라우저 엔진·웹 프로세스·타이머를 띄우지 않으며, 미리보기를 닫으면 렌더링 뷰를 해제합니다. 외부 이미지는 설명만 표시하고 HTML은 실행하지 않습니다. 복잡한 표, 수식, Mermaid 등은 지원하지 않습니다. 미리보기는 UTF-8 256KB 및 10,000줄 이하로 제한하며, 그보다 큰 문서도 원문 편집·저장은 가능합니다.

Finder 확장은 템플릿 본문이 없는 별도 메뉴 설정 도메인(`kr.techkwon.NewMemo.Menu`, 최대 32KB)만 읽습니다. 시작 화면도 메뉴 정보만 보관하고, 실제 생성·설정 편집 시에만 전체 설정을 읽습니다. 마지막 창을 닫으면 앱이 종료되고, 다음 Finder 메뉴 실행 시 다시 열립니다. 앱 종료 상태에서 파일을 생성하면 Finder에서 선택한 뒤 편집기 프로세스를 종료합니다.

실측과 재현 명령은 `PERFORMANCE.md`를 참고하세요. 현재 문서 크기, 창, 글꼴·macOS 캐시에 따라 메모리 사용량은 달라집니다.

## 빌드·설치

필수 환경: macOS 13 이상, Apple Command Line Tools의 Swift·SDK. 추가 라이브러리나 Xcode 프로젝트가 필요하지 않습니다. 현재 맥의 CPU 아키텍처로 빌드합니다.

```sh
bash scripts/test.sh
bash scripts/build.sh
bash scripts/install.sh
```

- 빌드 결과: `build/새 메모.app`
- 설치 위치: `~/Applications/새 메모.app`
- 설치 시 열려 있는 앱이 있으면 문서를 저장하고 종료하도록 안내합니다. 새 번들을 별도 임시 위치에서 검증하고 교체하며, 교체 후 서명·등록에 실패하면 이전 앱으로 복원합니다.
- Finder 메뉴가 보이지 않으면 앱에서 확장 설정을 열어 활성화 상태를 확인하세요. 다른 Finder 확장 프로그램이 같은 위치를 관리하는 경우 해당 프로그램과의 동작 차이가 있을 수 있습니다.

기본 빌드는 이 맥에서 쓰는 개발용 ad-hoc 서명입니다. 다른 맥에 배포할 때는 Developer ID 서명과 공증을 별도로 수행해야 합니다. 서명 인증서가 있다면 `NEWMEMO_SIGN_IDENTITY`에 인증서 이름을 지정해 빌드할 수 있습니다.

## 구조와 검증

- `Sources/Core/NoteFiles.swift`: 원자적 파일 생성, 템플릿 완전 쓰기와 URL 요청 검사. `O_EXCL`로 기존 파일·심볼릭 링크 덮어쓰기를 방지합니다.
- `Sources/Core/Settings.swift`: 형식·템플릿 유효성 검사와 로컬 preference 저장. Finder 확장은 메뉴 전용 도메인만 읽는 샌드박스 예외를 사용하며 파일 생성은 호스트 앱에 요청합니다.
- `Sources/FinderExtension/`: Finder Sync 메뉴와 편집기 실행. 파일을 읽거나 생성하는 작업은 앱이 담당합니다.
- `Sources/App/`: AppKit 시작 화면과 형식 설정 창, NSDocument 편집기, 저장·찾기·실행 취소.
- `Sources/App/MarkdownRenderer.swift`: 외부 요청 없는 네이티브 Markdown 렌더러.
- `Tests/`: 파일 생성·특수문자 경로·악성 요청·40개 동시 생성, 문서 인코딩·실행 취소·다시 실행·실제 저장·재열기 검사.

Finder가 전달하는 메뉴의 `tag`로 메뉴를 열었을 때의 폴더를 보존합니다. `representedObject`는 Finder의 프로세스 간 메뉴 전달에서 보존되지 않아 사용하지 않습니다. 편집 내용은 텍스트 저장소의 문자 변경을 관찰해 동기화하며 실행 취소·다시 실행 내용도 저장에 반영합니다.

실제 검증 범위와 결과는 `VERIFICATION.md`를 참고하세요.

로컬 검증 원본·개발 도구 기록(`build/`, `.omx/`)과 개인 설정은 공개 저장소에서 제외합니다. 공개 검증 요약은 [VERIFICATION.md](VERIFICATION.md), [STABILIZATION.md](STABILIZATION.md), [PERFORMANCE.md](PERFORMANCE.md)에 있습니다.

현재 별도 소프트웨어 라이선스는 지정하지 않았습니다.

기능 설계 참고: [mariusgm/newfile](https://github.com/mariusgm/newfile/tree/05819878e41f2a63b62ba83141c061552d2a630d) (MIT, 확인 commit `0581987`). 사용자 지정 형식·템플릿·메뉴 순서·하위 메뉴·도구 막대 구성을 참고해 기존 앱에 독립 구현했습니다. 새 메모의 한국어 내장 편집기와 호스트 앱에서 생성하는 구조는 유지합니다. 자동 업데이트 라이브러리는 포함하지 않습니다.

참고한 API: [Apple Finder Sync 안내](https://developer.apple.com/library/archive/documentation/General/Conceptual/ExtensibilityPG/Finder.html), [directoryURLs](https://developer.apple.com/documentation/findersync/fifindersynccontroller/directoryurls), [selectedItemURLs](https://developer.apple.com/documentation/findersync/fifindersynccontroller/selecteditemurls()).
